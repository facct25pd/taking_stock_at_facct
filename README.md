# Taking Stock at FAccT
Codebase for ACM FAccT 2026 paper *"Taking Stock at FAccT": Using Participatory Design to Co-Create a Vision for the Fairness, Accountability and Transparency Community*

The files processed in the src process the raw csv files that can be found in [the Pol.is results page](https://pol.is/report/r8zcsaxppvvhrbnvkceth). For figure 6, 7, and section 4.3 the relevant files can be found in the csv folder in this repo. Please note that the output for section 4.3 is a folder in which the votes are summarized per theme.
